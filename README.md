# RamaKalMedu.com — RKM Travel Hub

React + Vite tourism website for RamaKalMedu.com / RKM Travel Hub, Ramakkalmedu, Idukki, Kerala.

## Included
- Responsive React landing page
- Supplied Ramakkalmedu photographs and `RamaKalMedu.mp4`
- Stay, experiences, gallery, cinematic video, facilities, nearby attractions, group travel and contact sections
- RKM Travel Hub service information incorporated from the supplied website material
- Facilities/services: FreshUp rooms, dormitory, tent stay, campfire, swimming pool, food court, spices shop, fancy shop, jeep safari, homestay, windmill visit, vineyard visit, Tortoise Rock, bus/van support, tourist information, Wi-Fi, power backup and security
- Audience information: tourist groups, family trips, school/college tours, corporate and adventure groups
- Enquiry modal and WhatsApp contact flow
- Image lightbox gallery
